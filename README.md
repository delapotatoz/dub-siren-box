# Dub Siren Box

Dub siren web pour sound system : 6 pads à déclencher pendant les transitions entre deux vinyles, branchés sur une entrée ligne de la table de mixage.

- Sirènes synthétisées (Siren, Alarm, Wobble, Two-Tone, UFO…), effets (Bomb, Lick Shot, Riser…) et voix
- Réglages par pad (pitch, vitesse, profondeur, release, chute, hauteur), echo dub et volume
- Bibliothèque de sons, import de ses propres samples
- Clavier : `1`–`6` ou `A Z E / Q S D` (AZERTY)

Un seul fichier `index.html`, sans dépendance : ouvrir dans Chrome ou publier avec GitHub Pages.
